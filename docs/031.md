I want you to implement a new feature called:

"AI Travel Itinerary Planner"

CORE USER PROBLEM

Many travelers know how many days they have in a destination but do not know how to organize attractions into a practical itinerary.

Example:

"I have 5 days in Da Nang. What should I visit each day?"

FechTin Go should automatically generate a practical itinerary based on:

- Number of travel days
- Destination
- Geographic proximity between attractions
- Attraction importance/popularity
- Recommended visit duration
- Opening hours
- Best visiting time
- Full-day attractions
- Travel time
- User travel preferences
- Existing tour itinerary patterns / attraction co-occurrence data

The system must prioritize geographic efficiency and realistic travel time.

IMPORTANT PRODUCT PRINCIPLE

Do NOT build this as a simple LLM chatbot.

The itinerary must be generated by a deterministic/pluggable itinerary engine first.

LLM should only be used to:
- understand user preferences
- explain the generated itinerary naturally
- generate descriptions
- suggest alternatives

LLM must NOT invent attractions, opening hours, travel times, or factual data.
